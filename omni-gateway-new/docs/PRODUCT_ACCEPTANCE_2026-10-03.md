## 已观察的浏览器事实

1. **免费、缺价、失败分别表达**：免费请求和缺价请求同为零金额，前者显示“免费（显式零费率）”，后者显示“未定价（非免费）”；缺价样本仍 HTTP 200，没有新增调用阻断。失败样本独立显示 HTTP 503。
2. **免费计量**：免费详情包含上游实际用量输入 20、输出 10、合计 30，`estimated=false`、`source=upstream`；零金额账本保留正数量和价格版本 1、上游尝试与耗时。
3. **桌面抽屉**：1470×836 视口中，详情 top=0、right=1470、width=880、height=836，独立内部滚动；不追加到长列表底部。正文仅在单独勾选同意后读取，关闭即清理。
4. **键盘与刷新**：Escape 关闭后回到原详情按钮，列表 scrollY=538 保持；URL 保留 page。刷新恢复同一详情，正文同意重置且敏感正文未保留。
5. **小屏**：390×844 视口中详情 x=0、y=0、width=390、height=844，页面无横向溢出。可展开任务导航、以 Enter 进入本人密钥页。
6. **本人接入**：管理员和普通用户都有本人密钥入口。Base URL 仅一层 `/v1`；curl/Python 示例引用环境变量，不含实际密钥或内部上游地址。选择已有成功记录的本人密钥显示首次成功；访问、刷新和复制前后假上游模型调用计数均为 7。
7. **能力隔离**：普通用户白名单密钥仅列一个许可别名；查询管理员密钥能力返回 404，不泄漏对象存在信息。个人调用列表只取会话本人。
8. **明文生命周期**：新建本人测试密钥只在弹窗显示明文；通用提示、URL、localStorage/sessionStorage 均无该明文；确认保存后明文节点清理，列表保留掩码。
9. **个人诊断与历史**：本人失败记录显示安全中文摘要/建议、HTTP 状态和真实请求 ID；`#/myRequests?page=1&status=error` 筛选只显示失败，刷新恢复结果筛选，浏览器后退/前进恢复上下文。
10. **角色导航**：会话用户名入口显示真实 `me.username`，普通用户仅有账号中心、我的密钥、我的记录；直达管理请求页显示无权访问提示并回到允许视图。用户组与预算入口不存在。
11. **后端密钥强制边界**：两条创建路径伪造他人 user_id 均 403；归属转移 400 `key_owner_immutable`；管理员对他人编辑名称、重新启用和删除均 403，返回真实错误 code/request_id。旧用户组与预算管理路径返回 404。
12. **就绪与影响面**：别名页展示有效路由、供应商状态、协议和免费/缺价原因。无路由草稿创建 201，启用被 400 `alias_not_ready` 拒绝，重新读取列表确认仍未启用、有效路由为 0。为一个模型配置替代路由后，供应商影响面明确区分 1 个仍有替代、2 个失去最后路由；二次确认包含具体名称/数量和“不自动修改其它对象”提示，取消未执行变更。
13. **审计**：上述 403 被记为 denied，400 记为 failure，而非 success；前后摘要只含名称、归属、白名单、状态和到期等安全字段，无密码、密钥明文/哈希、凭据或正文。审计 result=denied 筛选与 URL 一致。
14. **价格本地操作**：表格每百万 Token 的 `0.000000000000000001` 转换成 API 每 Token `0.000000000000000000000001`；JSON→表格往返原值不丢失。免费快捷填零，本地双账试算为零；未保存草稿不创建版本，假上游调用数仍为 7。
15. **真实 SSO-only 设置**：通过本地假 OIDC 登录后，只显示新密码/确认两项并提示启用本地登录；设置成功后刷新为三项含当前密码。此前建立的第二个有效 SSO 会话再访问 me 返回 401；本地密码与 SSO 分别重新登录到同一账号，绑定不变。

16. **极小正费率真实落库**：`1e-1000` 成本/积分价格的合成调用 HTTP 200；PostgreSQL 查询有 3 条正数量账本、至少一条 cost>0、价格版本 1。积分量化为零仍为 `settled`，没有当作免费，精确成本非零。
17. **免积分独立核算**：显式积分费率为零而成本费率非零的调用记录成本 4 CNY、积分 0、`credits_free`；再调用时 `gateway.zero_credit_settlements` 前后均为 1，没有把显式免积分记为零积分异常（已有的 1 来自极小正积分量化）。
18. **最终后端 HTTP 烟测**：重建最终实现后，两条重复 RPM=10 规则允许 10 次，第 11 次 429；两条 TPM=61 规则仅累计实际 Token，3 次成功、第 4 次 429。成功记录、免费零金额账本及价格版本真实持久化；新建探针密钥与规则由脚本明确停用。两条代签路径 403、六类他人密钥变更被拒绝、旧 API 404、无路由草稿启用失败后仍未启用、个人查询隔离及 SSO 本地登录到原账号再次通过。
19. **最终浏览器与接入地址复验**：桌面抽屉 x=590/y=0/880×836；小屏 390×844 全屏无横向溢出，Escape 回原详情按钮并保留免费筛选 URL。移动菜单可用 Enter 进入本人密钥；选中真实成功密钥、鼠标复制 Base URL、键盘复制 curl/Python 与刷新，假上游计数 33→33。示例、URL 和 localStorage/sessionStorage 中未发现实际密钥或密码。
20. **实际 Base URL 修复**：发现开发 Vite 的 `/v1/models` 原先返回控制台 HTML，而非模型 JSON；新增 dev/preview `/v1` 代理并补回归。修复后后台 HTTP 及真实浏览器均从同源 Base URL 得到 HTTP 200 模型 JSON（5 个合成启用别名），模型调用计数仍 33→33，不只检查字符串拼接。

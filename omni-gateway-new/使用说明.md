# 使用说明：学号即用户名

配套文档见 `修改说明.md`（说明改了什么、为什么）。

---

## 1. 本次改动的文件

只有两个，都在 `backend/` 下：

```
backend/internal/httpapi/oidc.go    首次登录时账号叫什么名字
backend/internal/store/oidc.go      这个名字怎么写入数据库
```

除此之外**没有动任何东西**：数据库表结构、迁移脚本、前端、配置文件、
Dockerfile 与 docker-compose 均保持原样。

---

## 2. 生效方式

改的是 Go 源码，**必须重新编译后端并重启容器**才会生效：

```bash
cd <项目目录>
docker build -t omni-gateway-main-backend:latest .
docker compose up -d --no-build postgres backend
```

`postgres` 数据卷不需要重建，已有账号不受影响。

> 停止旧容器前请确认已备份 `.env`：`GATEWAY_MASTER_KEY` 决定数据加密，
> 丢失后已存的数据无法解密。

---

## 3. 使用方式

1. 浏览器打开网关地址（默认后端监听 `8080`，映射端口见 `BACKEND_PORT`）；
2. 点击「统一身份认证」按钮；
3. 跳转学校 CAS，用学号与密码登录；
4. 回跳后即为已登录状态。

**首次登录**会自动建号，账号名 = 学号（如 `256530319`）。
**之后每次登录**都在同一个账号上，不会重复建号。

管理员用 `.env` 中的 `GATEWAY_ADMIN_USER` / `GATEWAY_ADMIN_PASSWORD`
走本地口令登录，与学生 SSO 账号互不影响。

---

## 4. 验证是否生效

后端日志**不记录** OIDC 回调，靠日志看不出来。查库最准：

```bash
docker exec -it <postgres容器名> \
  psql -U "$POSTGRES_USER" -d "$POSTGRES_DB" -c '
  SELECT u.id, u.username, u.role, i.issuer, i.subject
    FROM users u
    JOIN oidc_identities i ON i.user_id = u.id
   ORDER BY u.id DESC
   LIMIT 10;'
```

**期望**：`username` 列直接是学号，`subject` 也是学号。

若 `username` 形如 `oidc-3f9a…`，说明该次登录的 claim 里没有可用的
`preferred_username`（或值含非法字符），此时按下方第 5 节排查。

---

## 5. 常见情况

### 5.1 `username` 仍是 `oidc-` 开头

说明 IdP 没有下发 `preferred_username`，或值不满足校验规则
（1–32 位，仅 ASCII 字母/数字/`.`/`_`/`-`，首字符非标点）。
请检查 IdP 侧的 claim 映射，确认 `preferred_username` 确实带着学号。

### 5.2 用户名带了后缀，如 `256530319-a1b2c3`

表示学号这个用户名**已被另一个无关账号占用**（常见于手工建过同名本地账号）。
系统保留了学号作为主干、追加确定性后缀把新号建了出来，登录可正常进行。
想恢复成纯学号，需要先处理那个占用同名的账号（改名或停用），
再删掉带后缀的账号让它重新建。后缀由 `(issuer, subject)` 决定，同一人永远一样。

### 5.3 同一个学生出现多个账号

多数是 **issuer 变了**。`issuer` 里包含授权服务地址，同一 IdP 若通过两个不同
地址（内网 IP / 对外域名）提供 OIDC，就会被当成两个身份各建一号。
解决办法是让 IdP 的 issuer 地址保持唯一且不变，与本次代码改动无关。

---

## 6. 回滚

两个文件恢复为改动前版本：

```go
// httpapi/oidc.go 第 251 行
Username:    oidcUsername(issuer, claims.Subject),
```

并删除 `oidcLocalUsername` / `normalizeOIDCUsername` / `oidcIdentitySuffix`
四处新增代码（`oidcUsername` 本就存在，不需改动），重新编译重启即可。
已建成的账号不会被自动改名或删除，如需清理请手工处理。
